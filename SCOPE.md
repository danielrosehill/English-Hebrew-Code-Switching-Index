# Scope

## In

Daniel Rosehill's own work on **English that contains Hebrew words**, on any platform (Hugging Face models, datasets and Spaces, plus GitHub repos):

- ASR models fine-tuned to transcribe Hebrew words in English speech.
- Audio and text datasets of code-switched English-Hebrew.
- Classifiers, lexicons and tooling that detect or normalise Hebrew words written in Latin letters.
- Evaluations that measure code-switching accuracy.

Vocabulary in scope covers both **Israel-specific** words (*teudat zehut*, *makolet*, *Bituach Leumi*) and **Jewish/diaspora** words that English ASR handles badly. Both TTS and ASR count, since they share data and vocabulary.

## Out

- **Hebrew-only** speech or text (no English matrix). See [Hebrew-Language-Projects-Index](https://github.com/danielrosehill/Hebrew-Language-Projects-Index) and [Hebrew-AI-Models](https://github.com/danielrosehill/Hebrew-AI-Models).
- **General speech tooling** (dictation apps, cleanup prompts, non-Hebrew fine-tunes). See [Speech-Tech-Index](https://github.com/danielrosehill/Speech-Tech-Index).
- **Third-party** projects. This index lists only Daniel's own work. Third-party Hebrew models belong in Hebrew-AI-Models.
- **Private repos.** This index is public. If a private working repo has a public tracker, link the tracker (for example English-Hebrew-Codeswitching-Parakeet-Finetune).

## Edge cases

- Resources with only *some* code-switched content go under **Adjacent**, not the main sections.
- Superseded datasets stay listed, with a note on what replaced them and any known defect, so that nobody trains on them unknowingly.
